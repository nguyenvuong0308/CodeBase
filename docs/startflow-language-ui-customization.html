Chọn version và phạm vi triển khai

Version được chọn bởi Remote Config, không phải bởi layout app. Xác định trước app dùng màn đầu flow, màn Settings, hay cả hai.

01

Bật Language và chọn version

Cập nhật default XML trước để app vẫn chạy đúng khi Firebase chưa fetch được; sau đó tạo cùng key/value trên Firebase Remote Config.

app/src/dev/res/xml/remote_config_defaults.xmlCấu hình debug/dev để QA. app/src/prod/res/xml/remote_config_defaults.xmlFallback thật được đóng gói trong release.
Remote Config — hai parameter JSON riêng
// parameter: application_config
{
  "is_enable_change_language_screen": true,
  "is_enable_introduction_screen": true,
  "is_always_show_intro_and_language_screen": false
}

// parameter: language_activity_config
{
  "version": 2,
  "time_show_loading_lfo": 3
}
FieldGiá trịÝ nghĩa
is_enable_change_language_screentrue/falseBật/tắt Language trong start flow.
language_activity_config.version1 hoặc 2Giá trị khác hợp lệ sẽ fallback V2 theo domain mapper.
time_show_loading_lfoSố giây hoặc bỏ trốngThời gian loading LFO nếu flow sử dụng cấu hình này.
is_enable_introduction_screentrueSau Apply đi tiếp Onboarding; nếu false đi Main.
Firebase không đọc object gộp như ví dụ minh họa bên ngoài. Trong console, application_config và language_activity_config là hai parameter riêng, mỗi value là JSON string hợp lệ.

Custom giao diện bằng resource của app

App override resource cùng tên của library. Không copy layout core nếu chỉ đổi màu, text, background hoặc ảnh.

startflow_language_config.xml
<resources>
  <!-- false = icon check; true = localized text -->
  <bool name="startflow_language_v2_apply_use_text">true</bool>
  <item name="startflow_language_v2_apply_text_value" type="string">
    @string/core_common_save
  </item>

  <!-- Có thể trỏ tới shape/selector/ripple của app -->
  <item name="startflow_language_v2_apply_background" type="drawable">
    @drawable/bg_language_apply
  </item>
</resources>

04

Nối destination của StartFlow

Core sở hữu Language/Onboarding, còn app cung cấp activity đích qua StartFlowNavigator. Không hard-code MainActivity vào module core.

RequiredModule.kt — binding tối thiểu
@Provides
@Singleton
fun provideStartFlowNavigator(): StartFlowNavigator =
  object : StartFlowNavigator {
    override fun mainClass(): Class<*> = MainActivity::class.java
    override fun otherLanguageEnd(): Class<*>? = null
    override fun mainPreloadAdPlaceNames() =
      listOf(AppAdPlaceName.ANCHORED_BOTTOM_HOME)
  }

Từ Splash

Gọi LanguageActivityNavigator.intentStart(..., fromSplash = true). Navigator tự chọn V1/V2.

Từ Settings

Truyền fromSetting = true; V2 dùng activity riêng và Back có interstitial place riêng.

Sau Apply

otherLanguageEnd() ưu tiên trước; nếu null thì Onboarding hoặc Main theo is_enable_introduction_screen.

Manifest: activities của StartFlow nằm trong manifest library và được merger đưa vào app. Chỉ khai báo thêm nếu app override hành vi manifest có chủ đích; tránh duplicate activity tùy tiện.
05

Build và kiểm tra theo đúng thứ tự

Tách kiểm tra resource, flow và ads để biết lỗi nằm ở app merge, Remote Config hay ad inventory.

  1. Build cả devDebug và prodDebug; không có lỗi duplicate/missing resource.
  2. Reset app data để Language xuất hiện như first open.
  3. Test V1 và V2 bằng default XML trước khi publish Firebase.
  4. V2 đi đủ ba bước và chỉ Apply ở bước cuối.
  5. Đổi icon/text/background Apply và kiểm tra state disabled.
  6. Xác nhận locale đổi, loading overlay chặn thao tác và destination đúng.
  7. Kiểm tra request/log đủ từng place_name trong bảng bước 03.
  8. Mở từ Settings, test native place và interstitial khi Back.
  9. Fetch/activate Firebase rồi lặp lại để phát hiện khác biệt với defaults.
  10. Nếu đi Onboarding, test xuyên suốt tới Main và toàn bộ ad place kế tiếp.
PowerShell — test và build hẹp
.\gradlew.bat :core:startflow:testProdDebugUnitTest
.\gradlew.bat :app:assembleDevDebug :app:assembleProdDebug
Nếu Gradle Test Executor báo Could not find or load main class Test: kiểm tra entry PATH có dấu quote thừa. Đây là lỗi command line của JVM worker, không phải assertion của StartFlow.
!

Lỗi thường gặp

Kiểm tra các điểm này trước khi sửa code core.

Đã set version 2 nhưng vẫn thấy V1
Kiểm tra parameter đúng tên language_activity_config, JSON hợp lệ, fetch/activate thành công và default XML của đúng flavor.
Apply background không đổi
Override startflow_language_v2_apply_background với type="drawable" trong module app. Đừng đặt một tên alias khác rồi kỳ vọng layout core tự biết.
Ads không hiện dù ad_id đúng
So chuỗi place_name với bảng bước 03, kiểm tra đúng list key, is_enable, trạng thái VIP/network và remote list version đang active.
V2 chỉ có ad ở bước đầu
Cần ba object riêng cho suffix language_1, language_2, language_3. Một object legacy không được tái sử dụng tự động.
Apply xong quay lại Language hoặc loading mãi
Kiểm tra StartFlowNavigator, navigateAfterChangeLanguage, activity recreation và destination Onboarding/Main. Không tự start activity song song với core.

Definition of Done

Remote keys đúng flavor · resources override từ app · mọi place_name resolve · navigator dẫn đúng đích · test first-open và Settings đều pass.
